# 🎮🎂 Розыгрыш: «игра 2048» → сюрприз-поздравление

Телеграм-бот с мини-аппом, который выглядит как обычная игра **2048**
(популярная по всей Азии головоломка). Друг заходит «поиграть», делает
несколько ходов — и тут экран взрывается конфетти с поздравлением
**«С Днём рождения, <имя>!»**

Ничего в ссылке, превью и сообщении бота не выдаёт подвоха — всё оформлено
как игра. Это и есть «клоакинг» в безобидном смысле: приманка = настоящая
играбельная игра, сюрприз прячется внутри.

---

## Что внутри

```
webapp/index.html     — мини-апп: рабочая 2048 + экран-сюрприз с конфетти
bot/bot.py            — бот: присылает кнопку «Играть в 2048»
bot/requirements.txt  — зависимости бота
```

---

## Шаг 1. Настрой поздравление

Открой `webapp/index.html` и найди блок `CONFIG` (в самом верху, в теге
`<script>`). Поменяй под себя:

```js
const CONFIG = {
  friendName: "",          // ← ВПИШИ ИМЯ ДРУГА, напр. "Чингиз"
  revealMode: "moves",     // когда показать сюрприз:
                           //   "moves"   — после нескольких ходов (незаметнее всего)
                           //   "instant" — почти сразу (короткий "лоадер", затем сюрприз)
                           //   "score"   — при достижении счёта
  revealAfterMoves: 6,     // для "moves": сколько ходов до сюрприза
  revealScore: 100,        // для "score": при каком счёте
  instantDelayMs: 2200,    // для "instant": сколько мс крутить "загрузку"
  titleTop: "С Днём рождения,",
  message: "Это был не бот с игрой 😏 Лови поздравление! ...",
  emojis: "🎂 🎈 🎁 🥳 🎊",
};
```

> Рекомендую оставить `revealMode: "moves"` — друг успеет втянуться в игру,
> и сюрприз будет максимально неожиданным.

## Шаг 2. Выложи мини-апп в интернет (нужен HTTPS)

Telegram открывает мини-аппы только по **https**. Самый простой бесплатный
способ — **GitHub Pages**:

1. Запушь этот репозиторий на GitHub (ветка уже готова).
2. В репозитории: **Settings → Pages**.
3. **Source** → *Deploy from a branch*. Выбери свою ветку и папку `/webapp`
   (или положи `index.html` в корень и выбери `/root`).
4. Через 1–2 минуты получишь адрес вида
   `https://твой-логин.github.io/имя-репо/`.
5. Открой этот адрес в браузере — должна запуститься 2048. Это и есть
   `WEBAPP_URL`.

Альтернативы для хостинга: Netlify (перетащи папку `webapp`), Vercel,
Cloudflare Pages — любой отдаёт статику по https.

## Шаг 3. Создай бота и «замаскируй» его под игру

1. В Telegram открой **@BotFather** → `/newbot`. Задай имя и юзернейм.
   Он выдаст **токен** (строка вида `123456:ABC-...`). Сохрани.
2. Сделай профиль бота «игровым» (это и маскирует превью ссылки):
   - `/setname` → `2048` (или `2048 Puzzle`)
   - `/setdescription` → `Классическая головоломка 2048. Собери плитки до 2048!`
   - `/setabouttext` → `Залипательная головоломка 2048 🎮`
   - `/setuserpic` → загрузи любую картинку-иконку 2048 (гугли «2048 game icon»).

   Теперь, когда друг получит ссылку на бота, в превью будет игра, а не ДР.

### (Рекомендуется) Прямая ссылка на мини-апп — без запущенного сервера

Чтобы не держать бота включённым 24/7, можно повесить мини-апп прямо на бота:

1. В @BotFather: `/newapp` → выбери своего бота.
2. Заполни название/описание/иконку (всё «игровое»).
3. **Web App URL** → вставь свой `WEBAPP_URL` из шага 2.
4. BotFather даст прямую ссылку вида `t.me/твойбот/имяприложения`.

Такую ссылку просто кидаешь другу — она сразу открывает игру. Сервер
запускать не нужно. Если идёшь этим путём — **шаг 4 можно пропустить**.

---

## Шаг 4. (Если хочешь именно сообщение-приглашение от бота)

Это вариант, когда друг пишет боту, а тот отвечает «зацени игру 👇» с кнопкой.

```bash
cd bot
pip install -r requirements.txt

BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER" \
WEBAPP_URL="https://твой-логин.github.io/имя-репо/" \
python bot.py
```

Бот работает, пока запущен скрипт (на твоём компе или любом VPS). Текст
приглашения и подпись кнопки меняются в начале `bot/bot.py` (`INVITE_TEXT`,
`BUTTON_TEXT`).

---

## Шаг 5. Прогон перед розыгрышем

1. Сам открой игру (через ссылку мини-аппа или кнопку бота) **с телефона** —
   мини-аппы лучше всего работают в мобильном Telegram.
2. Проверь: игра двигается свайпами, после `revealAfterMoves` ходов
   прилетает поздравление с нужным именем и конфетти.
3. Поправь `CONFIG` при желании, перезалей на хостинг — готово!

Удачного розыгрыша 🎉
