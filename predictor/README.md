# ⚽ footy — статистический анализатор футбольных матчей

Инструмент на Python, который разбирает матч (прежде всего **Лигу
Чемпионов**) как это делает опытный спортивный аналитик: оценивает силу
команд по статистике, строит вероятности **всех** основных рынков и ищет
ставки с **положительным матожиданием (value)** — там, где коэффициент
букмекера выгоден нам в долгую.

> ⚠️ **Честно и сразу.** Гарантированно выигрышных ставок не бывает. Модель
> даёт *вероятности*, а не точный исход. Смысл инструмента — не «угадать
> счёт», а находить ставки, где наша оценка вероятности выше той, что зашита
> в коэффициент. Это долгая игра на дисциплине и банкролл-менеджменте, а не
> способ «обыграть контору» за вечер. Ставь ответственно и только то, что не
> жалко потерять.

---

## Что считает

- **Исход 1X2** — победа хозяев / ничья / победа гостей, + двойной шанс.
- **Обе забьют (BTTS)** — да / нет.
- **Тоталы (Over/Under)** — 1.5, 2.5, 3.5 и любые линии, включая целые (с возвратом).
- **Азиатские форы** — целые, половинные и четвертные линии (с возвратом и разбиением ставки).
- **Точный счёт** — топ самых вероятных счетов.
- **Value + Келли** — при наличии коэффициентов: EV, честный кэф, перевес и рекомендуемая доля банка.

А также: **бэктест** стратегии на истории (ROI/yield), учёт **xG и травм**
(API-Football) и разбор **целого тура ЛЧ** с топом value-ставок.

## Как устроена модель

```
форма команд  ─►  ожидаемые голы (λ)  ─►  Пуассон + поправка Диксона–Коулза
                                               │
                                               ▼
                                        матрица счёта P[i][j]
                                               │
         ┌─────────────────────────────────────┼───────────────────────────┐
         ▼                 ▼                     ▼               ▼           ▼
       1X2              BTTS                 тоталы           форы      точный счёт
         └───────────────── сравнение с коэффициентами ─► поиск value (EV, Келли)
```

Что заложено «от аналитика»:

- **Вес свежести** — недавние матчи важнее (экспоненциальное затухание `decay`).
- **Дом / гости раздельно** — домашняя и выездная результативность считаются отдельно.
- **Регрессия к среднему (shrinkage)** — при малой выборке (а в ЛЧ её мало) сила
  команды подтягивается к среднему, чтобы не переобучаться на 2–3 матчах.
- **Диксон–Коулз** — поправка на то, что реальные матчи чаще заканчиваются
  ничьими низких счетов, чем предсказывает чистый Пуассон.
- **Контекстные поправки** — травмы лидеров, усталость, мотивация задаются
  ручными множителями `home_mult` / `away_mult`.

## Установка

```bash
cd predictor
pip install -r requirements.txt   # requests нужен только для режима fetch
```

Нужен Python 3.10+. Движок (всё, кроме `fetch`) работает без интернета и без
зависимостей.

## Быстрый старт

```bash
# Демо-матч (ничего настраивать не нужно):
python -m footy demo --bankroll 1000

# Разбор своего матча из JSON:
python -m footy predict examples/match_rma_mci.json --bankroll 1000

# Машинный вывод:
python -m footy --json demo
```

## Режим с реальными данными (API)

1. Получи ключ (бесплатный тариф football-data.org покрывает ЛЧ):
   https://www.football-data.org/
2. Скопируй `.env.example` в `.env` и впиши ключ:
   ```
   FOOTBALL_DATA_TOKEN=твой_ключ
   ```
   Файл `.env` в git не попадёт. **Ключ в чат/коммиты не вставляй.**
3. Запусти:
   ```bash
   python -m footy fetch --home "Real Madrid" --away "Man City" \
          --provider football-data --last 8 --bankroll 1000
   ```

Коэффициенты можно подать отдельным файлом, чтобы искать value:
```bash
python -m footy fetch --home "Real Madrid" --away "Man City" \
       --odds examples/odds.json
```

Поддерживается и **API-Football** (`--provider api-football`, ключ
`API_FOOTBALL_KEY`, у него есть xG и составы).

## Формат JSON-матча

Смотри `examples/match_rma_mci.json`. Коротко:

```jsonc
{
  "league": { "home_goals": 1.55, "away_goals": 1.25 },  // база лиги
  "context": {
    "decay": 0.85,        // вес свежести (0..1, больше = ровнее)
    "shrink_k": 3.0,      // сила регрессии к среднему
    "rho": -0.08,         // параметр Диксона–Коулза
    "home_mult": 1.0,     // поправка к голам хозяев (травмы/мотивация)
    "away_mult": 0.95
  },
  "home": { "name": "...", "matches": [ {"gf": 3, "ga": 1, "venue": "H"}, ... ] },
  "away": { "name": "...", "matches": [ ... ] },   // venue: "H" дома, "A" в гостях
  "odds": {                                         // опционально — для поиска value
    "1x2":    { "home": 2.05, "draw": 3.70, "away": 3.40 },
    "btts":   { "yes": 1.66, "no": 2.15 },
    "totals": { "2.5": { "over": 1.72, "under": 2.08 } },
    "ah":     [ { "line": -0.5, "home": 1.90, "away": 1.90 } ]
  }
}
```

`matches` — последние игры, **самый свежий первым**.

## Бэктест на истории

Проверяет, была ли стратегия прибыльной в прошлом — **без подглядывания в
будущее**: прогноз на каждый матч строится только по играм, сыгранным до него.

```bash
# Демо на синтетической «лиге» (идёт в комплекте):
python -m footy backtest examples/history_demo.json --min-ev 0.0 --min-matches 3

# Реальные данные — бесплатные CSV с коэффициентами (внутренние лиги):
#   скачай сезон с https://www.football-data.co.uk/  (напр. E0.csv)
python -m footy backtest E0.csv --min-ev 0.03 --stake kelly --bankroll 1000
```

Выводит: число ставок, оборот, прибыль, **ROI (yield)**, долю зашедших и
разбивку по рынкам. Параметры: `--min-ev` (порог value), `--min-matches`
(сколько истории нужно), `--form-window`, `--stake flat|kelly`, `--kelly-frac`.

> Если на истории минус — это честный сигнал: по этим данным и порогу играть
> не стоит. Так и должен работать настоящий бэктест.

## xG, составы и травмы (API-Football)

При провайдере `api-football` можно подтянуть **xG** (точнее голов отражает
силу) и учесть **травмы** автоматически:

```bash
python -m footy fetch --home "Real Madrid" --away "Man City" \
       --provider api-football --season 2024 --with-xg --injuries
```

- `--with-xg` — модель считает силу по ожидаемым голам, а не по фактическим
  (по 1 запросу на матч — расходует лимит).
- `--injuries` — число недоступных игроков снижает атаку команды (скромная
  настраиваемая поправка, т.к. данные не говорят, насколько важен игрок).

## Анализ целого тура ЛЧ

Разбирает все матчи тура разом и выдаёт **топ value-ставок по туру**:

```bash
# Сводка по туру (вероятности по каждому матчу):
python -m footy round --matchday 6 --provider football-data

# С коэффициентами — топ value-ставок тура, отсортированных по EV:
python -m footy round --matchday 6 --odds examples/round_odds.json \
       --top 10 --bankroll 1000
```

Файл коэффициентов — JSON с ключами вида `"Real Madrid vs Man City"`:

```json
{
  "Real Madrid vs Man City": { "1x2": {"home": 2.05, "draw": 3.7, "away": 3.4} },
  "Bayern vs PSG":           { "btts": {"yes": 1.7, "no": 2.1} }
}
```

Можно задать диапазон дат вместо тура: `--date-from 2026-01-20 --date-to
2026-01-22`, и отфильтровать по статусу: `--status SCHEDULED,TIMED`.

## Структура

```
predictor/
  footy/
    poisson.py          — ядро: матрица счёта (Пуассон + Диксон–Коулз)
    markets.py          — вывод всех рынков из матрицы
    value.py            — маржа, EV, перевес, критерий Келли
    analysis.py         — «аналитик»: форма (+xG, травмы) -> λ -> отчёт
    backtest.py         — бэктест стратегии на истории (без подглядывания)
    round_analyzer.py   — разбор целого тура + топ value-ставок
    report.py           — читаемые текстовые отчёты с вердиктом
    data/               — провайдеры: football-data.org, API-Football, JSON
    cli.py              — командная строка (demo/predict/fetch/backtest/round)
  examples/             — примеры матча, тура, истории для бэктеста
  tests/                — тесты (pytest), 44 шт.
```
